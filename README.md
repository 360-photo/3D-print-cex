# Цех РТК: эскиз

Условный цех с 25 роботами KUKA KR 120 R3100 на опорах, у каждого свой стол. У каждого робота можно выбрать G-code (пять встроенных панелей или свой файл с компьютера), запустить печать, поставить на паузу или остановить. Рука ведёт сопло по траектории, панель нарастает слой за слоем.

Страница работает целиком в браузере: файл G-code читается и считается на устройстве и никуда не отправляется. Подходит для компьютера и телефона.

Это эксперимент: размеры цеха условные (около 33 × 25 м).
